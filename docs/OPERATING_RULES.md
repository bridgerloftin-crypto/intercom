# Intercom 2.0 Operating Rules

1. Intercom coordinates work; Git proves work.
2. No secrets in messages.
3. Every handoff needs an owner, expected output, and status.
4. "Done" requires evidence.
5. HMWAS work follows the gate order and repo `VERSION.md`.
6. Agents should ACK work they accept.
7. Blockers should be structured, not buried in chat.
8. Long-term decisions should become MemPalace candidates.
9. Remote access should use Tailscale before any public tunnel.
10. If Intercom and Git disagree, trust Git for code and Intercom for routing/status.
